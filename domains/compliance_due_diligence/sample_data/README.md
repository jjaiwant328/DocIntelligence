# sample_data/

Synthetic RaceTrac store-development corpus spec (generated by
`notebooks/01_synthetic_corpus_store_dev.py`; uploaded to the domain volume, then PDF-converted).

Markets: Tampa FL, Dallas TX, Atlanta GA. Includes:
- feasibility request **emails** (`.txt`/`.eml`)
- municipal requirement documents
- alcohol / tobacco / business license documents
- zoning documents
- consultant correspondence
- **historical responses** (dated) — for "have we handled this before?"
- **before/after regulatory pairs** (e.g. Dallas alcohol v2024 → v2025 distance-waiver) — for change detection.
